# Project HERMES

> **H**igh-throughput **E**ngine for **R**esearch in **M**ulti-omic **E**valuation and **S**tratification

Project HERMES is an AI-assisted precision oncology platform designed to automate molecular cohort construction, multi-omic data integration, machine learning, and explainable artificial intelligence for cancer research.

---

## Features

- Automated TCGA/GDC integration
- Triple-Negative Breast Cancer (TNBC) cohort discovery
- Multi-omic dataset construction
- Dataset validation
- Feature engineering
- Machine learning model training
- SHAP explainability
- REST API
- PDF report generation

---

## Technology Stack

- Python
- FastAPI
- Scikit-learn
- Pandas
- NumPy
- SHAP

---

## Current Status

**Version:** 1.1.0

Project HERMES is currently a research platform developed for precision oncology applications using publicly available genomic data from TCGA.
